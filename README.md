# NodeBB Google Chat Email Integration Plugin

This plugin allows NodeBB administrators to integrate Google Chat notifications by entering an email address.

## Admin UI
- Template: templates/admin/plugins/google-chat-email.tpl
- Client script: static/admin.js
- Settings API: GET/POST /api/plugin/google-chat-email/settings

## Install
- npm install
- npm run bump to bump versions in package.json and plugin.json
